# 纪念证书与月球明信片设计方案

**定位。** 五站游园的终点是一份能保存、能回看的个人纪念；明信片则是任何时候都能写给别人的小作品。两者共用“月球来信”的邮政语言，但入口和资格分开：证书须集齐五站，明信片无需通关。以下是产品与视觉设计交付稿，不代表页面已经实现。

## 一、现状与设计目标

网站现在有月饼分拣站、月亮知识局、月下身份所、月光留言板、玉兔配送中五站。首页护照按本机 `stamps` 中的五个站点 ID 显示进度；完成后只引导制作明信片，还没有领奖页。月饼只保存最高分，知识保存最高正确数与最近一次成绩，人格保存最近一次结果，留言保存本机祝福列表，跑酷保存最远距离。明信片目前为一个 1000×680 的 SVG 构图，提供三种纸色、寄信人和最多 60 字正文，可预览、下载 SVG、复制文字；这些操作没有作品历史。关键代码依据：[护照完成状态](/Users/Zhuanz/Desktop/中秋/src/pages/HomePage.tsx:25)、[盖章存储](/Users/Zhuanz/Desktop/中秋/src/lib/storage.ts:3)、[现有明信片](/Users/Zhuanz/Desktop/中秋/src/pages/PostcardPage.tsx:8)。

本次设计解决三个问题：五章与真实游玩结果如何在同一张纪念品上说清楚；写过的祝福和制作过的卡片如何找回；多版式如何产生不同的叙事和排版，而不是只换底色。所有记录先存在当前浏览器，页面持续说明清除浏览器数据会移除本机收藏，跨设备同步另列后续阶段。

## 二、贯穿体验：先游园，再领取

首页护照为每站显示三态：未到访、已到访、已完成且盖章。打开站点就标记“已到访”，不等同于获得印章；盖章仍按既有规则：月饼 60 秒结束且至少正确分拣一枚，知识完成八题，人格完成十二问，留言提交非空祝福，玉兔在体力耗尽前跑满 3000 米。首页进度只数完成章，未完成者点站点卡片可继续玩。五章齐全之前，“纪念证书”可浏览样式和内容说明，但领取按钮显示还差哪些站，不能生成带个人章的正式文件。

每站结算先完整呈现本局结果和“再玩一次”。若它恰好补齐第五章，结算区增加“领取月球漫游纪念证书”入口；不自动弹窗、不遮住成绩、不在游戏中途打断。用户也能之后从护照和收藏夹回到领奖页。明信片从首页与各站页始终可进入；通关只解锁专属“五星纪念邮票”作为可选装饰，八种普通版式和文字编辑不设门槛。

领奖流程是“填写展示昵称与个人话语 → 预览三版证书及正反两面 → 确认领取 → 约 0.6 秒盖上朱砂印 → 下载或收藏”。无账号的本机体验只使用展示昵称，不要求实名，也不暗示身份核验。昵称预览时可改，确认后固定为该版本的展示名。盖章动效有“跳过”按钮，系统启用减少动态效果时直接呈现静态终态。首次确认领取时锁定五站成绩快照与已知完成日期；“颁发日期”为领取当天，与站点完成日期分开。重复打开、重复下载始终引用这一版。后来重玩得更好时，页面只提示“有新成绩，可生成新版”，由用户显式创建新版本，旧证书仍可找回，不悄悄改写。

## 三、证书内容与三种设计

网站外层继续使用现有深色夜空与月面氛围，领奖预览中央是一张明显不同于背景的“纸”。默认款 **月白荣誉证** 用暖月白纸、纤细金框、疏朗标题和原创朱砂印，侧重中央的荣誉宣告。第二款 **深蓝星航证** 用深蓝底和极细星图，侧重五站航线与终点。第三款 **五站护照内页** 用分页、站点格与盖章位，侧重分站记录。三款的构图侧重不同，细节以实施时的完整预览为准。印章图形由本站原创绘制，避免借用机构徽章或模拟官方认证。

正面必须同时看见“五站摘要、个人话语、祝福、盖章”：月饼取领奖时已保存的**最佳完整局**，标“最佳”，分数、正确分拣数与连击都来自该局；知识取**最佳完整八题局**，标“最佳”，正确数和逐题选择来自同一局。人格取最近一次完整结果，留言取用户选定的一条祝福，跑酷取最近一次成功抵达 3000 米的局及该局月币数。祝福默认取最近一条仍存在的本机留言，用户可改选或另写一句仅用于证书；没有可用留言时保留空白输入，不引用示例祝福充当个人留言。背面或第二张为 **游园记录页**，逐站写已知完成日期、关键动作、结果与对应印章，并说明“记录来自此浏览器”。正面与记录页均可预览、分别下载，也有“一并下载”入口，不能让详情只藏在页面上。

成绩展示遵守原游戏口径。有量化数值才展示实际分数、正确数或距离；人格以角色及十二个场景作答摘要呈现，留言以实际祝福和提交记录呈现。不开一个并不存在的五站“总分”，不计算百分位，不估算游玩时长。旧进度若已有章却无完整局明细，仍承认完成；月饼或知识只存最高值时可标“历史最佳分/历史最佳正确数”，但不补正确分拣、连击或逐题动作，其余缺口写“历史明细未记录”。跑酷旧“最远纪录”可能来自未通关局，因此不能当成证书胜局成绩。关闭私人留言时，正反两面和所有打包下载都隐藏相同的私人文字；分享版是从不可变原件生成的衍生输出，不改写收藏原件。

证书数字版默认导出 1080×1440 PNG，即竖向 3:4，确保中文字体、金线和印章清晰；同时提供可选的 A4 打印 PDF，排版保持安全边距并检查跨页。证书编号是本站本机版本标识，不宣称具有官方效力。收藏页标明版本、领取日期、版式和“原成绩/更新后成绩”；再次下载同版不生成新条目，换版或改话语则明确创建新版本。

**示例证书文案（演示值，非真实成绩）。** “谨授予月球旅人 **小满**「**全境漫游者**」纪念称号。你已走过五座月球站点：月饼分拣最佳完整局 **860 分**，月亮知识最佳完整局 **7/8 题**，其余站点与祝福按本人记录填写。月球邮局寄语：愿你收藏今晚的月光，也记得把团圆带回日常。”正式证书只填领取时可核实的本机快照。

## 四、八款月球明信片：构图先于配色

编辑器先选版式，再选独立色盘。八款都允许改文字、LOGO 和合适的装饰，但保留各自清楚的结构边界：

| 版式 | 主要构图与适用场景 |
| --- | --- |
| 经典航邮（主打） | 左侧月球与轨道，右侧地址、邮戳和正文；适合第一张中秋问候。 |
| 月相留白 | 月相沿边缘排列，大面积留给一行标题与安静的祝福。 |
| 桂花诗笺 | 纵向笺纸、桂枝边饰和短句分行，适合诗意祝福。 |
| 地月票根 | 地球到月球的虚构航程、撕线与收件人栏；“票根”是本站原创推演。 |
| 旅行手账 | 两三枚有界贴纸、日期签和手写注记，适合记录一次游园。 |
| 月下合影 | 一张用户照片为主体，旁边是月亮、图注和短祝福。 |
| 玉兔童话 | 连续小画格与玉兔送信插画，适合孩子或轻松语气。 |
| 团圆窗景 | 圆窗或四格构图，在“远近共月”的场景间放入主标题。 |

首版完成经典航邮、月相留白、桂花诗笺、地月票根四款；其余四款与照片拼贴在第二阶段。模板库每款显示缩略图、适合的文字长度和一键“用此版式”，并且保留用户已经写好的收/寄件人、标题、正文与上传图。若从长文版切到短文版导致排版溢出，应提示“此版式建议 60 字，可切回或编辑”，绝不静默截断。色盘只是同一构图的视觉选项，不能被计入八款数量。

## 五、明信片编辑规则与祝福示例

左侧编辑、右侧实时预览；手机上改为编辑与预览切换。文字字段包括收件人、寄件人、主标题、正文。正文设“短句 60 字”和“长信 120 字”两种容量，由版式可容纳区域决定；长文时清楚提示当前版式的限制。提供三类字体：端正印刷体、温柔宋体、克制手写体；成品比例明确为横向 3:2、竖向 3:4。贴纸只能落在模板预设区域，提供大小与旋转的少量刻度及复位，避免无限画布和文字互相遮盖。

LOGO 区提供三个内置“月球来信”标记、一个可输入文字章，以及上传 PNG、JPEG、WebP。上传后默认放在角落，按 `contain` 适配，不裁掉品牌文字；用户可调整到模板许可的位置、替换或删除。照片版的相片槽和 LOGO 槽分开，上传 LOGO 不占合影位置。导出前预览完整边界，检查中文换行、图片清晰度与角落安全区。首版提供 PNG 下载与文字复制；下载是本机动作，不会自动发给联系人或发布到留言板。

示例文字分五类，每类两句，均为本站原创，可一键填入后继续修改：

| 对象 | 示例 A | 示例 B |
| --- | --- | --- |
| 家人 | 今晚月亮替我先到家，愿饭桌上的笑声一直热着。 | 不管相隔几站，想起你们，回家的路就亮了。 |
| 朋友 | 把今天收集的月光分你一半，下次见面再把故事讲完。 | 愿你的日子像桂花香，细小却总有惊喜。 |
| 爱人 | 我们看的是同一轮月亮，我想念的是你看月亮的样子。 | 今夜把距离折成信纸，写满我们还要一起去的地方。 |
| 自己 | 谢谢今天认真走到这里的我，明天也慢慢发光。 | 愿我记得停下来赏月，也记得继续奔向喜欢的生活。 |
| 同事 | 愿忙碌有回响，休息有月光，节后再一起把事情做好。 | 这段路多亏与你并肩，祝你中秋安宁、事事顺手。 |

## 六、收藏夹、数据与旧进度

收藏夹有三个明确分类：**证书、明信片、文字**。明信片草稿自动恢复，但每次击键只更新当前草稿，不新建历史卡片；点击“生成并保存”才保存导出图片和编辑参数快照。重复下载同版本不重复存；从历史打开编辑时先建立副本，以免覆写原件。文字收藏需要显式点“收藏这句话”，复制或填入卡片都不等于收藏。历史卡片显示缩略图、版式、时间和“重下/编辑副本/删除”，文字卡片显示内容与来源。删除前确认，并说明删除本机作品不影响站点印章。若浏览器拒绝写入或存储配额已满，明确提示“未保存到本机”，保留当前编辑状态并提供直接下载；用户清理空间后可重试保存，证书领取也不能在写入失败时显示“领取成功”或“已收藏”。

数据上以现有 `moon-garden:` 键继续兼容，增加版本化的 `journey`：每站 `visitedAt`、`completedAt`、最近与最佳**完整局记录**、必要的尝试摘要。最佳局按原游戏成绩比较，同分可取最近完成的一局；整局数值和行为始终同一条记录。月饼记录难度、分数、正确/漏单和最高连击；知识记录正确数及题目与选择；人格记录角色与十二个选择；留言关联真实祝福 ID；跑酷记录胜负、路程和月币。证书另存不可变的 `certificate` 快照与模板版本；明信片保存一个 `postcard-draft` 和多个 `postcard-history`；文字另存 `word-favorites`。照片、LOGO 以及导出图片放 IndexedDB，元数据留轻量存储，不把图片塞进 `localStorage`。模板保留 `templateId` 与 `templateVersion`，更新模板后旧作品仍按原版参数重导。

旧 `stamps` 仍作为既有完成事实；读取时只接受五个合法站点 ID，旧章可以推断“已到访”，但到访日期未知，不能补造时间。旧章不要求重新通关，无明细处必须显式标注缺失。现有月饼最高分为原生数字字符串，知识、人格、留言等为 JSON；迁移读取应容错，不因单项损坏清空其他记录。留言被删除后印章不撤销，证书祝福可以重新填写。用户首次打开收藏夹时看到“记录仅保存在当前浏览器，清除数据后不可恢复”的说明；后续跨设备同步须另有账户与用户授权。

## 七、分期与验收

**首版**交付三款证书、五站摘要和记录页、领取与历史版本、PNG 及可选 A4 PDF；明信片交付前四款版式、文字编辑、三类 LOGO 入口、示例、PNG 下载、草稿和三类收藏。数据只在本机保存。**第二阶段**交付旅行手账、月下合影、玉兔童话、团圆窗景及照片拼贴，并评估跨设备账户、分享链接与双面导出增强；任何公开分享都由用户主动触发。

验收以以下场景为准：

1. 新访客只进入五站而未达到条件，护照显示“已到访”，证书无法领取；真正完成五站后，在最终站结算看见领奖入口。
2. 首次领取可预览三版正面与记录页，盖章支持跳过与减少动态效果；下载的 1080×1440 PNG 与 A4 PDF 包含姓名、五章、真实成绩、个人话语、祝福和对应日期。
3. 重新游玩提高成绩后旧证书和旧下载不变；显式生成新版才更新快照。关闭私人留言后分享版不含留言，收藏原件仍保留。
4. 旧浏览器有五章但缺明细仍能领取；证书明确写历史明细未记录，跑酷最远距离不冒充胜局，已删祝福不被恢复。
5. 不通关也能制作普通明信片；切换四种首版构图保留文字和图片，过长文字提示溢出；LOGO 能上传、替换、删除且不被裁切。
6. 刷新后草稿恢复，生成卡片进入历史，重下不重复，编辑旧卡创建副本；文字只有显式收藏才进入文字栏，清缓存影响有清楚提示。

## 八、参考事实与本站推演

[Adobe Express 的证书说明](https://www.adobe.com/express/create/certificate)列出标题、组织及 LOGO、获得者、颁发日期、签名等常见字段，并介绍徽章和边框。本站借鉴“成就信息有层级”，月白纸、朱砂印与正反两页为原创设计。[美国国家公园管理局的 NHA 护照](https://www.nps.gov/subjects/heritageareas/nhas-passport.htm)介绍在地点收集纪念章的实体护照；本站把“到访”和“达成后盖章”拆成数字状态。[NASA Flight Log Experience](https://www.nasa.gov/stem-content/flight-log-experience/)明确有个性化登机牌、飞行日志、认可印章与任务徽章；本站仅借鉴“旅程记录可带走”，不是 NASA 合作或认证。

[Adobe Express 旅行明信片库](https://www.adobe.com/express/templates/card/postcard/travel)确有 “Red And White Mail Postcard” 与 “Collage Travel World Postcard”，说明航邮与拼贴是不同视觉组织。[Paperless Post 自定义模板库](https://www.paperlesspost.com/cards/category/customizable-templates)可见 “Photo and White Space”“Golden Ratio”“Calligraphy”，提示文字、照片与留白可有不同重心。[Greetings Island 上传设计页](https://www.greetingsisland.com/cards/upload-your-own)列有 “Polaroid” 和 “Double Frame”，并说明可上传图片和调整文字；其[卡片页](https://www.greetingsisland.com/cards)介绍预写消息、保存并命名草稿。[MOO 明信片页](https://www.moo.com/us/postcards)提供不同尺寸、模板、空白编辑与上传完整设计。本站的地月票根、五站成绩编排、三类收藏和领取机制均为此项目的设计推演，不是上述网站的现成功能。
